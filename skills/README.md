# Example skills

`internal-comms/` is copied unchanged from [Anthropic's official skills repository](https://github.com/anthropics/skills/tree/ca45fc496a3436251f191354091d557da31c15b5/skills/internal-comms), revision `ca45fc496a3436251f191354091d557da31c15b5`. Its Apache-2.0 license is retained in `internal-comms/LICENSE.txt`.

The starter discovers it automatically. Try asking for a weekly team update with Progress, Plans and Problems; include the team name, dates and facts to cover. The skill loads its matching guideline from `examples/` before drafting the update. See the [skills guide](../docs/skills.md) for compatibility and adding your own skills.

These example files are part of the repository, not the npm package. Copy the skill folder into your application's `skills/` directory when using the standalone starter.
