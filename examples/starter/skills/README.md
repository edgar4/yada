# Skills

Copy a skill folder here, including its `SKILL.md`, references and license, then restart the assistant. The name in the skill's YAML frontmatter must match its folder name.

Standard skill folders from Claude, Cursor and Codex can be reused. Scripts require appropriate host tools; they do not execute automatically. See the [skills guide](https://yada.edgar.co.ke/skills.html) for compatibility details.
