FROM ZERO TO A TOOL CALL

Start small.
Make it yours.

Run the deterministic catalog demo first. No provider account or API key needed.

Then add your provider configuration to a private .env file and run the same example with a live model.

Full setup guide →

Live calls use your provider account. Keep keys on the server.

01 Run the local demo 
git clone https://github.com/edgar4/yada.git
cd yada
nvm use
npm ci
npm run demo
02 Configure your private .env 
YADA_LLM_PROVIDER=anthropic
YADA_LLM_MODEL=claude-sonnet-4-6
YADA_LLM_API_KEY=your-provider-key

Copy .env.example to .env, then run npm run demo:live.
