TypeScript agent runtime for Node.js

Build an AI assistant that works inside your product.

Yada is the server-side runtime for in-app assistants. Connect a model, turn your APIs and databases into typed tools, and let users approve every change. It runs in your Node backend, behind your auth, with your keys.

From a chat message to real work

The model decides what to do. Your code decides what’s allowed.

  1. Pick a model

    Hosted or local, through one provider contract. Switching providers is a config change, not a rewrite.

  2. Expose your tools

    Wrap HTTP APIs, SQL queries or MCP servers as tools with Zod-validated inputs. Authorization is checked before every call.

  3. Approve the writes

    Write tools pause with a preview. Nothing changes until an authenticated user confirms.

  4. Pick up where it stopped

    Encrypted checkpoints and operation receipts in SQLite, PostgreSQL or MySQL let runs resume after a crash or deploy.

It only knows what you let it.

Yada is Hebrew for “to know”. Here, that knowledge comes from you: the tools you register, the data they can reach and the permissions of the user asking. It’s a library inside your service, not a hosted platform.

How the runtime works →

Your backend, your keys

Your auth, checked on every call

Pass in the authenticated user and tenant. Yada rechecks authorization before each tool runs and again before a write executes.

Try it without an API key.

The demo runs a catalog lookup against a scripted model, so you can watch a full tool call before connecting a provider.

When you’re ready, add your provider settings to a private .env and run the same example against a live model.

Full setup guide →

Requires Node 24. Live calls use your provider account; keys stay on your server.

Run the demo 
git clone https://github.com/edgar4/yada.git
cd yada
nvm use
npm ci
npm run demo
Connect a live model 
YADA_LLM_PROVIDER=anthropic
YADA_LLM_MODEL=claude-sonnet-4-6
YADA_LLM_API_KEY=your-provider-key

Copy .env.example to .env, then run npm run demo:live.
