Open-source AI agent harness

Add an AI agent that gets real work done inside your app.

Yada is a free, open-source agent harness. Plug in a model, give it your APIs as tools, and your users can search, book, apply or update just by chatting.

What an agent harness does

Chatbots talk. Agents act. The model decides what to do, your code decides what’s allowed, and Yada carries it out.

  1. 01

    Pick any model

    Anthropic, OpenAI, Gemini, DeepSeek, or local models through Ollama and llama.cpp. Switching is a config change, not a rewrite.

  2. 02

    Give it your tools

    Turn HTTP APIs, SQL queries and MCP servers into tools the agent can call. Inputs are validated and permissions checked on every call.

  3. 03

    Users just ask

    Place orders, edit profiles, send invoices: if you define it, users can do it by chatting. You set the rules, Yada follows them.

  4. 04

    Never lose a run

    Conversations and run state persist in SQLite, PostgreSQL or MySQL, so agents resume after a crash or deploy.

Built into TalonHR

TalonHR, a recruitment platform, runs its AI agent on Yada. Job seekers and employers get work done by chatting. Real screen recordings with live model output on demo data, at 2× speed.

It only knows what you let it.

Yada is Hebrew for “to know”. Your agent knows only the tools you register, the data they reach and the permissions of the user asking. It’s a library in your backend, not a hosted platform.

Browser SDK and widget →

Your agent, one command away.

On Node 24, one command scaffolds a working agent: config, SQLite storage, example tools, a skills folder and the chat widget, all wired together.

Add your model key to .env and run npm start. Password protection is optional.

Full setup guide →
Create your agent 
npx @edgaralochi/yada init my-agent
Connect a live model 
YADA_LLM_PROVIDER=anthropic
YADA_LLM_MODEL=claude-opus-5-5
YADA_LLM_API_KEY=your-provider-key

Set these in my-agent/.env, then run cd my-agent and npm start.
